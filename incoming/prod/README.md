Сюда добавляются продуктивные спецификации: DOCX и необязательный ZIP с XSD.

Создавайте отдельную папку для каждой поставки. Пример: 2026-11-12/10110_v3.1.docx и 2026-11-12/schemas.zip. Несколько DOCX одной поставки могут использовать общий ZIP рядом.

После push или merge в main импорт и публикация выполняются автоматически. Подробные правила и порядок отправки pull request — в корневом README.md, раздел «Новые спецификации через GitHub».
