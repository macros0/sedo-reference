# Обратная загрузка сопоставлений Excel

Пользователь выбрал применение только в браузере. Общая публикация и backend не требуются.

## Подходы
1. Локальный импорт существующего XLSX и сохранение проверенных пар в localStorage — выбран пользователем.
2. Общие соответствия через GitHub PR — отложено пользователем.

## Поведение
- На сравнении кнопка загрузки XLSX, предпросмотр пар и ошибок, явная кнопка применения и сброс.
- Импортируются только строки «Подтверждено», исходный путь, новый путь и комментарий. Описания/ограничения всегда берутся из текущих сохранённых XML-деревьев, а не редактируемых листов Excel.
- Метаданные книги должны совпасть с точными revision_id выбранных редакций; обратная ориентация разворачивается. Для новых редакций соответствия автоматически не переносятся.
- Несуществующие пути/формулы в значимых ячейках блокируют применение; неподтверждённые строки пропускаются; повторы одной пары объединяются. Разделение/объединение допустимы как несколько явных пар. Сопоставление родителя не распространяется на детей автоматически.
- Сопоставленные пути исключаются из обычных добавлений/удалений, свойства сравниваются существующим механизмом, пути и комментарии показываются на карточке. Пары без различий видны отдельно. Остальные поля сравниваются как прежде.
- Набор сохраняется по паре точных редакций в localStorage, доступен в обратном направлении. При недоступном хранилище работает в текущем сеансе с понятным уведомлением. Повреждённые данные не применяются молча.
- Повторный экспорт сохраняет применённые пары, решения и комментарии, включая разделение поля на несколько строк.
- Файл читается локально существующей ExcelJS, без сетевой отправки, выполнения формул или макросов. Лимит файла 10 МиБ; проверка ZIP-метаданных ограничивает заявленный распакованный объём 64 МиБ.

## Проверка
Node-тесты сравнения, импорта, сохранения/сброса и обратного направления; реальный 101/10110; браузерный цикл экспорт→правка→импорт→предпросмотр→применение→проверка изменений→перезагрузка→сброс; отрицательные сценарии чужой пары и неверных путей.
