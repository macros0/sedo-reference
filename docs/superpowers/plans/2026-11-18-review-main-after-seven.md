## Валидация XML и ручные сопоставления

### 1. P2 · Через anyAttribute можно обойти fixed глобального атрибута

Глобальный `m:instant` с типом `xs:dateTime | xs:integer` используется явно через `ref` в элементе `direct` и через строгий `xs:anyAttribute` в элементе `wild`. Дополнительное правило создаётся для `direct`, а альтернативная схема ослабляет глобальный `fixed`. Для `wild` правило отсутствует. Скачанный Python-валидатор и настоящий WASM приняли `42` и отличие в последней дробной цифре. Исходный нативный валидатор отвергает `42`. [Построение правил](../../../xsd_bundle.py#L475) · [Ослабление ограничения](../../../xsd_bundle.py#L657).

- [x] Генерировать проверку разрешённых объявлений по QName и `processContents`, учитывая явное использование. Ослаблять глобальный `fixed` только вместе с проверкой всех соответствующих мест. Сопоставить итоги Python и WASM.

### 2. P2 · Валидатор отклоняет эквивалентный смешанный список с pattern

Фиксированное написание списка из `dateTime | integer` заканчивается на `Z 7`. Эквивалентное написание использует смещение `-01:00` и `007`. Исходный `pattern` допускает оба написания. Проверка составляет третью строку `Z 007`, которую отвергает тот же `pattern`. Python и WASM возвращают «Не удалось точно сравнить». [Python](../../../xsd_validate.py#L345) · [WASM](../../../web/validation-worker.js#L156).

## WSDL и история выпуска
