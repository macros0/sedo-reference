Перечисления `xs:float` и `xs:double` сравниваются с точностью binary32 и binary64 соответственно. Проверены показательная запись, `INF`, `-INF`, `NaN`, сохранение ошибочных написаний и граница точности. Значения `16777216` и `16777217` совпадают для `xs:float` и различаются для `xs:double`. До исправления `1` и `1.0E0` давали ложное изменение для обоих типов. После исправления прошли наборы сравнения, журнала и экспорта.

Девять адресных Node-наборов завершились с кодом 0. Два новых сценария Chromium прошли с ресурсами локальной сборки и изменёнными скриптами из `web`. В этом прогоне Playwright отдавал локальные файлы через перехват запросов, поскольку отдельный HTTP-сервер не был доступен по порту 4199. Штатный общий прогон на пересобранном сайте учитывается в отчёте по всей рабочей копии.

В старой книге строки с решением «Удалено» не содержат признака наследования. Если предыдущий экспорт уже записал в строку такое решение, при чтении оно сохраняется как явное.
