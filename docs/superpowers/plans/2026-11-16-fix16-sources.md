# Исправления источников и импорта № 1, 4–8

16 ноября 2026 года. Работа выполнена в существующем грязном checkout; прежние изменения сохранены. Коммита, публикации и сетевого сбора не было.

- № 1 исправлен первым: обе инструкции поставки включают `schema.py`. Регресс извлекает списки модулей непосредственно из инструкций, копирует их в пустую папку и запускает Python с `-I` без импорта из checkout и с запретом сети. Оба реальных манифеста prod/test подтверждаются с прежними `content_id`.
- № 4: только CLI `sync.py` получает проектный `update_lock` перед сбором. Вызов `sync()` из уже защищённого обновления не захватывает блокировку повторно. Занятая блокировка предотвращает создание `state`; независимый каталог успешно получает `current.json` и `history.json` с локальными ответами вместо сети.
- № 5: SHA-256 входящих файлов вычисляется блоками по 1 МиБ через `update()`. Проверены большой файл без чтения целиком и настоящий CLI `--check` непустой поставки при удалённом `hashlib.file_digest`; проверка не меняет состояние проекта.
- № 6: при отсутствии `title` исходное имя берётся из официальной редакции того же контура либо стандартного вычисленного названия. Переименованные ручные строки не используются как значение по умолчанию. Три импорта «без title → с title → без title» восстанавливают название, сохраняя ID и первое событие.
- № 7: встроенная схема без `targetNamespace`, содержащая декларации, включается в архив. Схемы-обёртки только с импортами продолжают пропускаться, чтобы сохранить прежние архивные ID. Регресс сохраняет оба корня `plain` и `qualified` и раскрывает оба дерева.
- № 8: сопутствующая страница определяется парой «контур + официальный хост». Поддержаны prod-алиас `lk.fss.ru` и опубликованный путь `//mchd.html`; запрос идёт к текущему официальному хосту того же контура. Ссылки другого контура, чужого хоста, HTTP, с credentials или нестандартным портом не создают ложных `source_page`. Старый fixture `test_embedded_xsd` исправлен: ссылка test теперь использует свой хост вместо prod-алиаса.
