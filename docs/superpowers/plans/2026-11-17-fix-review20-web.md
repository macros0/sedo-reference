- №9: рабочие копии XSD получают расширение `.xsd`, включая исходный `Part0.XSD`; переписанные ссылки указывают на новые имена, исходные байты остаются в ZIP. До публикации браузерного URL проверяются 256 файлов, 32 МиБ JSON/закодированных схем, 8 МиБ gzip и ограничения дополнительных проверок. Для превышения сохраняется готовый ZIP, без `validation_download`, с `validation_error`, видимым в карточке.
- №13,17: сравнение нормализует булевы формы XSD и стандартные значения флагов; отображение сохраняет исходное написание. Сортировка перечислений использует строгий порядок, различающий разные Unicode-последовательности. Реальные переходы true → false и strict → skip остаются изменениями.
- №14: экспорт исключает автоматическое совпадение под удалёнными предками с обеих сторон. Явные пары сохраняются. Проверен XLSX → загрузка → предпросмотр → применение в прямом и обратном направлениях, с соседней веткой и явным потомком.
- №15: успешный SourceCraft heartbeat требует завершения и наблюдения обоих контуров с читаемыми датами. В браузере отсутствующая дата даёт неопределённость, старое наблюдение любого контура — устаревание даже при свежем общем отчёте. Неполный heartbeat не подтверждает обработку новых снимков.
- №16: история проверок и публикаций заменяет старую запись того же ID по номеру попытки, времени обновления и завершённости. Устаревшая попытка не побеждает новую.
