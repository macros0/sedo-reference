## План исправлений

Каждый этап можно принять отдельно. Для работы с незакоммиченными файлами сохранить исходную копию и переносить нужные изменения выборочно на базу `6b3495c` или её проверенного преемника. Производные файлы пересобрать из выбранных исходников после изменения правил.

1. [ ] **Сделать проверку и запись ежедневного обновления согласованными (#1).** В `.github/workflows/check-sfr.yml` и `pages.yml` обеспечить проверку именно того собранного `site`, который попадёт в Git. Выполнить `verify.py`, WASM и Playwright до записи данных в `main`. Приёмка на изолированном кандидате с принудительно проваленным браузерным сценарием — шаг записи и deploy пропущены, предыдущий SHA сохраняется. При успехе проверенный кандидат доходит до публикации.
2. [ ] **Воспроизвести источники проверяемого снимка и восстановить кэш (#2, #4).** Перед повтором в `verify.py` восстановить библиотеки обоих контуров по данным самого снимка. В `collector_feed.py` проверять оболочку и содержимое манифеста до признания кэша пригодным. Добавить в `tests/test_history_review_regressions.py` и `tests/test_collector_feed.py` сценарии SourceCraft без WSDL-ссылки, режима home, повреждённой даты и ошибочной удалённой копии. Приёмка — тот же SHA снимка, восстановление после повторного импорта и сохранение старого указателя при ошибке источника.
3. [ ] **Исправить транспорт коллектора (#3, #8).** В `collector_transport.py` и `sync.py` применять паузу и бюджет к каждому фактическому запросу, включая разрешённый переход. Освобождать результат Future после записи и ограничить очередь. На локальном подставном транспорте проверить 302 → 200, остаток бюджета в один запрос и остановку после ошибки. На серии обычных файлов проверить, что число удерживаемых двоичных результатов ограничено числом обрабатываемых задач. Итоговые байты объектов и снимка должны совпасть с исходной реализацией для того же набора ответов.
4. [ ] **Сохранить файлы, необходимые для `xs:include` (#5).** В `wsdl_sources.bridge` дополнить конкретную зависимость из WSDL того же контура. Сохранить приоритет собственного файла документа и диагностику неоднозначности. Добавить в `tests/test_wsdl_sources.py` три случая — отсутствующий локально include, локальная копия с тем же именем и два разных подходящих кандидата. В первом случае дерево и комплект должны собраться и проверить контрольный XML.
5. [ ] **Согласовать дерево и аудит с семантикой XSD (#9–11).** В `schema.py` различить неявный `xs:anyType` и анонимный пустой комплексный тип. 8. [ ] **Зафиксировать окончания строк для ресурсов сайта (#15).** В `.gitattributes` задать LF для исходных и публикуемых CSS и SVG. Проверить из двух чистых копий с LF и `core.autocrlf=true`: после сборки должны совпасть байты ресурсов, версии ссылок в HTML и сам `site/index.html`.
