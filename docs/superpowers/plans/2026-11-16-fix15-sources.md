## Поведение

- **№ 2.** Полный URL публикации остаётся в каждой строке источника. Для HTTP
  используется адрес без фрагмента. Очередь группирует такие ссылки и один раз
  скачивает/разбирает ресурс, затем передаёт результат всем ссылкам. Первичный
  запрос и перенаправление проверяют фактический адрес после удаления фрагмента;
  ограничения HTTPS, хоста, порта и каталога сохранены.
- **№ 5.** Оба пути импорта используют `filename_metadata` из `manual_import.py`.
  Дата выделяется до разбора версии, компоненты даты используют одинаковый
  разделитель. Проверяются в том числе перекрывающиеся кандидаты внутри
  числовой версии: приоритет у полного четырёхзначного года, затем у последней
  даты. Поддержаны дата в скобках, пробелы и описательный суффикс.
  Dotted version не отдаёт свои компоненты дате. Проверены `3.10`, `3.0.12`
  и `3_0_12` перед датой. Ручная дата заменяет вычисленную до календарной
  проверки, а повторная поставка и коррекция сохраняют идентичность редакции.
- **№ 6.** Для доказательства одинакового старого состояния сравниваются DOCX,
  ZIP и XSD соответствующего контура, без производных WSDL-сопоставлений.
  PDF и навигационные ссылки не создают ложную неоднозначность. Реальное
  различие DOCX либо схемного ZIP сохраняет `unavailable`. Старое решение
  `unavailable` пересматривается; новое содержит версионированный хеш
  подтверждений. Повтор с тем же доказательством пропускается, изменение
  подтверждённых наблюдений или переходов снова разрешает проверку.
- **№ 7.** Обход `bridge` хранит эффективное пространство имён вместе с путём
  XSD. Схема без собственного пространства наследует его по `xs:include` и
  передаёт вложенному включению. Посещённые контексты ограничивают циклы;
  прежний приоритет DOCX и диагностика неоднозначных кандидатов сохранены.
