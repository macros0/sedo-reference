## Результаты проверок

- В отдельной рабочей копии построены поля и сайт для 264 редакций. Изменились JSON полей ровно 40 редакций. У всех 230 wildcard в этом каталоге эффективное ограничение равно `##any`. Совпали все ID редакций и сохранённые байты DOCX и исходных XSD.
- В Chromium прошли все девять сценариев файла `catalog-sources-and-validation.spec.cjs`. Сайт обслуживался локально по HTTP. Для итогового прогона в отдельной сборке были обновлены два скрипта с подписями и поиском ручных документов.
- Прошли 36 адресных Python-тестов в `test_schema_content` и `test_xsd_bundle`, а также Node-наборы сравнения, сводок, Excel, просмотра полей, группированных редакций, журнала замечаний и браузерной валидации. Проверка дополнительных ограничений атрибутов прошла с Python и настоящим WASM в отдельной копии. В основной рабочей копии во время параллельной работы над №9 этот набор фиксировал исходный отказ по типу `Code` в дополнительно включённой схеме. Итог интегрированного прогона учитывается в общей приёмке.
