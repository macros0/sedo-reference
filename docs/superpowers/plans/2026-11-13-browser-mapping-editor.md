# Browser Mapping Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** Менять, добавлять и исключать пары тегов/комментарии в браузерном предпросмотре; явно отделить черновик от применённого сравнения.

**Architecture:** mapping-draft.js — чистая модель строк, выбора, валидации и пересчёта относительных предложений; mapping-editor.js — интерфейс редактора, поиска/страниц и применения. comparison-mapping.js сохраняет импорт и localStorage, связывает компоненты. compare.js ожидает обновление результатов и показывает подтверждение.

**Tech Stack:** Vanilla JS, существующая ExcelJS, Node/VM tests, CUA для проверки интерфейса.

## Диагностика
На открытой странице пользователя реально наблюдались 15 применённых пар (1 удаление) и 16 подтверждённых строк загруженного, но ещё не применённого предпросмотра, включая socialAssistNum→processNum. После действий пользователя и перезагрузки наблюдались 16 сохранённых пар, 0 удалений, 3 добавления. Точный сбой обновления страницы не воспроизведён; нужна регрессия мгновенного обновления для URL с базовым message=10510 и явная индикация черновика. Пользовательский набор не сбрасывать.

## Decisions
- Редактируются оба XML-пути и комментарий; выбор тегов с поиском по пути/описанию, только из выбранных схем.
- Можно создать набор без Excel, добавить пару, исключить подтверждённую строку и удалить ошибочную связь.
- Изменение строки сначала сохраняется в черновик. Основная кнопка явно применяет весь отмеченный набор и обновляет сравнение; открытая незавершённая форма блокирует применение.
- До применения localStorage и сравнение не меняются. Липкий баннер показывает неприменённый черновик и различие с сохранёнными парами.
- Автопредложения пересчитываются при изменении родителя, ручные пары сохраняют приоритет; удалённая в черновике связь не появляется повторно автоматически.
- Смена фильтра/страницы сохраняет правки и отметки. Дубликат выбранной пары и неизвестный путь запрещены; split/merge допустимы.
- Применение ожидает обновление результата, показывает подтверждение и прокручивает к счётчикам; ошибки обновления видны. Excel реэкспортирует применённые браузерные правки.
