### 4. P2 · WSDL с целевым пространством имён теряет полную схему

Индекс связей между встроенной схемой и включёнными файлами создаётся только для схем без `targetNamespace`. На корректном примере с `targetNamespace`, `root.xsd` и `types.xsd` нативный валидатор применяет ограничение типа. Сопоставление индивидуального DOCX оставляет сообщение без готовой редакции, а модульное сопоставление может сообщить о неоднозначности. [Отбор точек входа](../../../wsdl_sources.py#L211) · [Существующая регрессия без пространства имён](../../../tests/test_wsdl_sources.py#L192).

- [x] Добавить вариант существующей регрессии со своим namespace и ограничением из соседнего include. Проверить модульный и индивидуальный DOCX, отсутствие ложного объединения с отдельным архивом и одинаковый результат Python и WASM.

### 5. P2 · Аудит DOCX пропускает изменение `fixed` для union

Значение `p:code` в типе `QName | integer` проходит аудит и при смене привязки `p` с `urn:A` на `urn:B`. На тех же схемах валидаторы принимают взаимоисключающие экземпляры. Сравнение редакций уже хранит выбранный член union и раскрытое имя. Аудит атрибутов переходит к сравнению текста раньше этой проверки. [Сравнение ограничений в аудите](../../../audit_individual_tables.py#L286) · [Вызов из модульного аудита](../../../audit_module_tables.py#L325) · [Модель union](../../../schema.py#L705).

- [x] Проверить индивидуальный и модульный DOCX с одинаковым префиксом и разными URI, разными префиксами с одним URI, неизвестной привязкой и совпадающим лексическим значением разных типов.

### 6. P2 · Сравнение редакций теряет пространство имён `xs:NOTATION`

### 7. P2 · Валидаторы принимают отличающийся `fixed` у атрибута `xs:dateTime`

Валидация штатным Python-скриптом из ZIP и реальным WASM принимает два разных значения `dateTime` с дробными секундами. При `fixed` с окончанием `…6781Z` значение `…6782Z` тоже даёт успешный результат для прямого атрибута и для атрибута через `ref`. Точная календарная проверка формируется для элементов. В опубликованных редакциях таких атрибутов сейчас нет. [Отбор точных ограничений](../../../xsd_bundle.py#L481) · [Вычисление в браузере](../../../web/validation-core.js#L89).

- [x] Для обоих движков проверить точное равенство, эквивалентное смещение часового пояса и отличие в последнем десятичном разряде. Включить прямое объявление, глобальный атрибут через `ref` и соседний элемент с тем же типом.

### 8. P3 · Одинаковые байты скрывают подмену пути импортированного XSD
