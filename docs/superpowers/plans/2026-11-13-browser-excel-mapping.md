# Browser Excel Mapping Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** Локальное повторное сравнение с подтверждёнными пользователем парами XML-путей из XLSX.

**Architecture:** compare-core принимает необязательный массив ручных пар. Новый comparison-mapping.js отвечает за чтение XLSX, проверку редакций/путей, локальное хранение и предпросмотр. compare.js показывает результат; exporter сохраняет пары при повторной выгрузке.

**Tech Stack:** Vanilla JavaScript, закреплённая ExcelJS 4.4.0, localStorage, Node assertion tests.

**Spec:** ../specs/2026-11-13-browser-excel-mapping-design.md

## Global Constraints
- Применение только в браузере; не трогать исходные схемы и чужие незавершённые WSDL-изменения.
- Данные ограничений из справочника; явные подтверждения и точные ID редакций.

## Review Focus
- Два пути с одинаковым именем: ручная пара должна вытеснять только использованные узлы.
- Разделение/объединение и смена сторон сохраняют все пары.
- Старые экспортированные книги распознаются; формулы и чужие ID блокируются.
- Хранилище недоступно/повреждено: видимое уведомление и безопасный fallback.
- При переходе между редакциями незавершённый импорт не применяется к другой паре.
