Новые проверки сравнения охватывают одинаковые и различные значения, отсутствие зоны, точность дроби до наносекунд, переход даты при смещении, строковый тип без бинарной нормализации, QName с одинаковым URI и различными описаниями. Существующие проверки даты, текущей публикации, URI QName и исторических ID сохранены.

Chromium проверяет комментарий и снятый выбор дочерней пары после дерева/возврата, изоляцию обратного направления, отсутствие записи в localStorage до применения, сохранение только выбранных пар и отсутствие воскрешения применённого/отменённого черновика. Node дополнительно проверяет, что восстановленный после перемонтирования черновик объединяет независимую правку другой вкладки и продолжает отклонять конфликт комментариев по прежней базе.

## Дополнительное ревью

После независимого ревью воспроизведены и исправлены ещё две границы этих изменений:

Возобновлённый предпросмотр удерживает прежнюю базу для обнаружения конфликтов; новый читает текущую сохранённую запись. Отмена также обновляет показанный статус. Известная числовая версия теперь имеет явный приоритет перед неизвестной; все перестановки выбирают `2.10` и предыдущую известную `2.9`. Регрессия прошла.
