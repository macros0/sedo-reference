# Excel для ручного сопоставления XML

Пользователь выбрал XLSX. Выгружается вся выбранная пара редакций в текущем направлении независимо от экранных фильтров.

Книга: Сопоставление (редактируемые новый путь, решение и комментарий), Было, Стало (все исходные поля и ограничения, включая union), Изменения, О выгрузке (источники, версии, ссылки и методика). Совпадение полного пути можно подставить, но подтверждение всегда ручное. Разные корни/переименования автоматически не связываются. Описания для выбранного нового пути подтягиваются точным поиском; разделение/слияние можно описать дополнительными строками.

1. Тесты полного экспорта, направления, ручного подтверждения, сохранности ограничений и безопасного текста.
2. Локально закреплённая ExcelJS 4.4.0 (MIT), загружается только по нажатию. Браузерный продукт должен работать на GitHub Pages и без сети; закрытый Codex artifact-tool не является зависимостью продукта. Для проверки экспортированного файла применяется импорт/просмотр artifact-tool.
3. Кнопка на странице сравнения, обработка загрузки/ошибок; сборка, документация и CI.
4. Проверка реальной пары 101/10110, обратного направления, одинаковых редакций, браузера и книги. Рецензирование, публикация, проверка Pages.

## Проверка реализации

- Node: синтетические и реальные 101/10110, оба направления, одинаковые редакции, точные пути без автоподтверждения, union, текст вместо формул из источника, roundtrip XLSX, ссылки HTTP/file.
- Шесть прежних Node-наборов и тесты архива/сборки DOCX прошли; verify.py подтвердил целостность.
- Edge: настоящее скачивание 101→10110, 10110→101 и 101→101 с заведомо пустым экранным поиском. Количество строк в XLSX полное; библиотека загружается по требованию. Широкое и узкое окна.
- Независимый импорт artifact-tool: просмотр диапазонов и PNG; после замены E6 на benefitResponse/benefit5 пересчитались F6 (описание пособия по уходу за ребёнком) и G6 (ограничения).
- Read-only рецензия: исправлены file-ссылки на index.html и OOXML-префикс _xlfn.IFNA; замечания закрыты.
- Полный обязательный Python-набор и все Node-проверки выполняются также при публикации в GitHub Actions.
