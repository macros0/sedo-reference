# Исправления аудита № 2, 3, 9, 10

16 ноября 2026 года. Изменения внесены в существующую рабочую копию без коммита и публикации. Сетевой сбор не выполнялся. Прежние незакоммиченные изменения сохранены.

- № 2: каждое раскрытие карточки получает отдельные `fields`, `field_declarations` и счётчик `expanded_fields`. Исходное состояние восстанавливается в `finally`; временная декларация именованного типа удаляется из служебных индексов. Регресс: 100 карточек по 501 полю проверяются полностью без расходования общего лимита.
- № 3: `ValueError` дополнительной карточки даёт конкретную запись в `notes` с номером таблицы, файлом, путём и причиной. Пропущенная карточка не увеличивает число проверенных; следующая карточка проверяется. Загрузка исходного архива остаётся вне локального обработчика исключений. Передача notes проверена через `schema_review.compare_revision`, включая неиспользуемый `Tags` с `xs:list`.
- № 9: `review_field_links.attach_schema_sources` проходит декларацию, именованные типы и цепочку базовых типов. Источник конкретного facet содержит полный архивный путь, SHA-256 исходных байтов и неизменяемую ссылку `sources/<sha>.xsd`; официальный URL сохраняется отдельно, если он есть в provenance WSDL. Более строгая числовая граница и переопределённое перечисление отбираются из действующего ограничения. Учитываются также карточки неиспользуемых типов без XML-пути. `schema_review` сохраняет `xsd_source` и при необходимости `xsd_sources`; `xlocation` обновляется для прежних потребителей. Формат согласован с исполнителем журнала/Excel.
- № 10: вложенный SOAP payload разбирается в самостоятельное дерево с сохранением namespaces. В Base64 и вложенной форме диагностируются одинаковые `request/number`, значение `banana`, правило и ссылка на поле.

## Дополнительное ревью происхождения fixed

Финальное ревью обнаружило неоднозначное распознавание слова `fixed` внутри значения pattern или enumeration. Исправлено узко: свойство определяется только начальным маркером `fixed =` / `fixed=` либо началом диагностики `Фиксированное значение:`. Регресс сначала показал четыре неверных перехода к main.xsd; после исправления семь вариантов проходят, включая настоящие fixed-свойства и fixed-значение со словом pattern. Сортировка имён facet, добавленная координатором для детерминизма, сохранена.

Повтор той же профильной команды на окончательном коде: **49 тестов прошли**, 21,967 с.
