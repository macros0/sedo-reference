# Код-ревью справочника СЭДО и план исправления

17 ноября 2026. Проверена рабочая копия ветки `codex/fix-review-16` с локальными изменениями поверх `9c85e0bf339ff604db3fa8a3736a8ef09e60320f`. Текущий снимок источников — `6581db63a1768b984f134e7b4cdae74f1a320df056ecd0aa6aa6a22a9839b7`. Номера строк относятся к этой рабочей копии.

**Цель** — сохранить подтверждённые редакции при обновлении и обеспечить соответствие между исходным документом, результатом аудита и тем, что видит пользователь. Основание — [ТЗ](../../../SPEC.md), [описание пользовательских сценариев](../../../README.md) и наблюдения ниже.

Ревью охватило сбор СФР, домашний сборщик и импорт SourceCraft, ручной импорт, восстановление, каталог и генерацию полей, аудит DOCX, подготовку XSD, локальный валидатор, интерфейс, сравнение, Excel, сборку сайта и workflows. Интеграция сторонних ExcelJS и libxml2/WASM проверялась через интерфейсы проекта. Сценарии чтения API и изменения публикаций СФР моделировались локально. Фактическое состояние внешних сборщиков и GitHub Pages в результаты не входит.

**Проверка исходной копии.** Все 518 тестов Python из 47 модулей прошли (99 в первой группе и 419 в остальных модулях). Прошли 28 наборов Node и 51 сценарий Chromium. Проверка `--all-editions` скомпилировала 142 основных и 2 дополнительных комплекта XSD в WASM. `verify.py` дважды восстановил один и тот же снимок по 145 ссылкам и 110 загруженным файлам. Чистая сборка сайта из текущих данных во временную папку дала 264 редакции и те же 1 312 файлов, что в рабочем `site/`. Совпали имена и SHA-256 каждого файла. Браузерные тесты выполнены на уже установленной версии Playwright 1.65.0 из локальной копии зависимостей, с HTTP-сервером на loopback.
