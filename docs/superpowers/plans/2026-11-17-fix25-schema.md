# Исправления №13–19: XSD и аудит DOCX/XML

17 ноября 2026. Изменения проверены относительно `fix25-baseline.tmp/original.zip`; прежние локальные изменения сохранены. Коммит, внешние запросы и перегенерация рабочих `data/` и `site/` не выполнялись.

| № | Исправление и проверка |
|---|---|
| 13 | `Schema.qname_namespace` разрешает зарезервированный `xml` без явного `xmlns:xml`. Дерево содержит импортированный `xml:lang`; скачиваемый комплект и реальный WASM принимают `ru`, отклоняют `123` и отсутствие обязательного атрибута. |
| 14 | Обход дополнительных правил использует существующий `_schema_components`, исключающий аннотации и пользовательские payload. Пользовательский `price type="currency"` и цитата `xs:element type="UnknownQuotedType"` в `appinfo` не мешают подготовке комплекта. Python/WASM принимают decimal `1.0` при `fixed="1.00"`, отклоняют `2`. |
| 15 | `fixed/default` сравниваются через типизированное XSD-ограничение атрибута: decimal, integer, boolean, dateTime и правила whiteSpace. QName сравнивается по URI и локальному имени с независимым контекстом цитаты и XSD; одинаковое написание больше не скрывает различие URI. Неизвестный контекст даёт оговорку, а отсутствие ограничения не смешивается с QName неизвестного контекста. |
| 16 | В индивидуальном аудите список детей проверяется по существующему `contentModel`; `all` не задаёт порядка, `sequence` задаёт. Сравнение цитат канонизирует порядок ветвей `all/choice`, сохраняя вложенные композиторы и их кратности. |
| 17 | Модульный аудит сопоставляет композицию цитаты с существующим `contentModelBounds`, включая порядок sequence, вложенные группы и кратности групп. Замечание публикует читаемую модель и исходное местоположение карточки. |
| 18 | Исходные тексты абзацев Word сохраняются; заголовки распознаются по отдельному очищенному представлению. XML-значение `a ` + перевод строки + ` b` сохраняет длину 5. |
| 19 | Заполнители исключают только категории ошибок значений XSD. Неизвестный элемент `unknown` со значением `string` и запрещённый дочерний элемент простого типа остаются структурными замечаниями с путём. |
