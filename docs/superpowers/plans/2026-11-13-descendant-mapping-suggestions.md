# Descendant Mapping Suggestions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** По подтверждённой паре родительских блоков предлагать вложенные XML-поля с одинаковым полным относительным путём.

**Architecture:** Чистая функция suggestDescendants() дополняет предпросмотр импорта; выбор предложений применяется и сохраняется существующим механизмом. Исходные деревья и compare-core не меняются.

**Tech Stack:** Vanilla JavaScript, существующая ExcelJS, Node assertion tests.

## Requirements and decisions
- Ручные пары из Excel имеют приоритет. Для вложенной ручной пары действует ближайший родитель с обеих сторон.
- Полное совпадение относительного пути с учётом регистра, сегментов и @атрибутов; одного имени листового тега недостаточно.
- Неоднозначные split/merge предложения и занятые вручную узлы не выбираются автоматически; причины показываются отдельно.
- Предложения видны в предпросмотре с источником, родителем и относительным путём. Можно исключить отдельную пару или снять/выбрать все. Весь список доступен через страницы.
- До кнопки применения ничего не сохраняется; выбранные предложения становятся подтверждёнными парами существующего формата, попадают в повторный Excel.
- Для ранее применённых родителей есть кнопка открытия предпросмотра новых вложенных предложений.
- Ограничения продолжают браться из схем; неподошедшие относительные пути остаются обычными добавлениями/удалениями.
