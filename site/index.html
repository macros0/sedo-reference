Добавить спецификации

Справочник обновляется автоматически каждое утро: проверяются продуктивный и тестовый контуры СФР, новые редакции добавляются, а прежние сохраняются.

Загрузка через GitHub — запасной способ добавить спецификации, например полученные в Telegram до их публикации на сайте СФР.

Для ручной загрузки положите DOCX и, если есть, ZIP со схемами в папку нужного контура на GitHub.

Продуктивный контур Тестовый контур

Создавайте отдельную папку для каждой поставки. Сохраняйте имена СФР или используйте 10110_v3.1.docx. Архив XSD размещается рядом.

После push или принятия pull request в main скрипт проверит набор и опубликует новые редакции. Для pull request сначала выполняется пробный импорт без публикации.

Правила загрузки и отправки pull request в README

Публикации продуктивного и тестового контуров показаны раздельно. Источник и редакция доступны в карточке сообщения.
