Добавить спецификацию

Загрузчик доступен только на этом компьютере. Публикация разрешена владельцу GitHub macros0.

Выберите файлы, полученные от СФР отдельно. Сначала будет создан предпросмотр; сохранение и публикация выполняются после вашего подтверждения.

Для дерева тегов и сравнения загрузите ZIP со всеми XSD-зависимостями. Без ZIP будет сохранён исходный DOCX с пометкой «Схема не загружена».

Эта редакция уже есть в справочнике. Дубликат создан не будет.
